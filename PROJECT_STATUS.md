# Life in Akwa Ibom — current build status

## Implemented in this build
- Responsive game dashboard and page navigation
- Character name and avatar selection
- Local browser save and JSON export
- Virtual cash, XP, levels, reputation, energy, hunger, fun, social, hygiene, and bladder meters
- In-game clock and activity time costs
- Job shifts and career unlocks
- City exploration rewards
- Virtual businesses and income collection
- Home-interior activities: bed, kitchen, shower, sofa, toilet
- Home purchase and weekly rental mechanics
- Daily missions
- Global Town Square chat UI with local demo messaging
- Optional Supabase Realtime chat integration, pending project configuration

## Still required for a public, multi-player launch
- Create/configure Supabase and test live chat across independent devices
- Real user accounts and cloud saves for game state
- Server-authoritative validation for money, career progress, and purchases
- Chat reporting, blocking, moderation dashboard, abuse prevention, and privacy/retention rules
- A navigable city map with character movement and original custom artwork
- Cross-browser/mobile QA, accessibility testing, analytics/privacy consent, terms, and hosting

This project is a playable prototype. It does not currently include an in-world multiplayer simulation or cloud game saves. No visitor or popularity outcome is guaranteed.
